PPAWakeUp


ช่วยให้ PPA Tatip ทำงานต่อเนื่อง เงียบสงบ และไร้ปัญหาโปรแกรมค้าง ได้อย่างง่ายดายด้วยปุ่ม Windows+P


ผู้พัฒนา: chai chaimee

ลิงก์: https://github.com/chaichaimee/PPAWakeUp


บทนำ

PPAWakeUp เป็นแอ็ดออน NVDA ที่สร้างขึ้นเพื่อช่วยให้เอนจินอ่านจอภาพ PPA Tatip ทำงานได้อย่างราบรื่นร่วมกับ NVDA


เป็นที่ทราบกันดีว่า PPA Tatip มักจะหยุดทำงานเงียบๆ (ค้าง/ดับ) ในบางสถานการณ์ เช่น เมื่อต้องอ่านตัวอักษรภาษาเอเชียบางประเภท หรือเมื่อปุ่มดำเนินการในหน้าต่างไฟล์ (Open, OK, Save, Yes) ได้รับโฟกัสทันทีที่หน้าต่างปรากฏขึ้น PPAWakeUp จะเฝ้าระวังสถานการณ์เหล่านี้และเข้ามาช่วยแก้ไขให้อัตโนมัติ พร้อมทั้งยังให้คุณใช้ปุ่มคีย์ลัดคุ้นเคยเพียงปุ่มเดียวคือ Windows+P ในการบังคับปิดและเปิด PPA Tatip ใหม่ได้ทันทีทุกครั้งที่ต้องการรีสตาร์ท


นอกเหนือจากการกู้คืนระบบจากการค้าง แอ็ดออนนี้ยังรวมเมนูขนาดเล็กสำหรับการดูแลรักษา PPA Tatip ในชีวิตประจำวัน เช่น การเปิดหน้าต่างตัวเลือก, การสำรองและคืนค่าพจนานุกรมส่วนตัวของคุณ รวมถึงการเปิดไปยังโฟลเดอร์ติดตั้งได้โดยตรง


ปุ่มคีย์ลัด

Windows+P
กด 1 ครั้ง : ปลุก PPA Tatip (บังคับปิดและเปิดใหม่)
กด 2 ครั้ง : เปิดการตั้งค่าตัวเลือก PPA Tatip
กด 3 ครั้ง : เปิดเมนูจัดการ PPA Tatip
PPAWakeUp จะนับจำนวนครั้งที่คุณกดปุ่ม Windows+P รัวติดต่อกัน (ภายในครึ่งวินาทีของการกดแต่ละครั้ง) โดยจะรอครู่หนึ่งหลังจากการกดครั้งสุดท้ายเพื่อดูว่ามีการกดซ้ำอีกหรือไม่ จากนั้นจะทำงานตามจำนวนครั้งที่กดจริง: กด 1 ครั้งจะปลุก PPA Tatip, กด 2 ครั้งจะเปิดหน้าต่างการตั้งค่า และกด 3 ครั้งขึ้นไปจะเปิดเมนูจัดการ
คีย์ลัดนี้ถูกดักจับในระดับลึก (Low-level) เพื่อให้ไม่ว่าคุณจะกดกี่ครั้ง NVDA จะบังคับปล่อยปุ่ม Windows ให้คืนตัวกลับขึ้นมาเสมอ ซึ่งช่วยป้องกันไม่ให้ระบบ Windows ค้างคิดว่าปุ่ม Windows ยังถูกกดค้างอยู่ ซึ่งอาจทำให้คุณพิมพ์อักษร "p" ไม่ได้จนกว่าจะรีสตาร์ทเครื่อง

คุณสมบัติการทำงาน

ปลุก PPA Tatip (กด 1 ครั้ง)

การกด Windows+P เพียง 1 ครั้งจะบังคับปิด PPA Tatip ตัวที่ทำงานอยู่และเริ่มทำงานใหม่ทันที นี่คือคำสั่งหลักในการกู้คืนระบบเมื่อ PPA Tatip เกิดค้างหรือไม่ตอบสนอง


ขั้นตอนการทำงานเมื่อกด Windows+P 1 ครั้ง:


1. NVDA จะประกาศคำว่า "Wake up" และส่งเสียงบี๊บโทนต่ำสั้นๆ
2. แอ็ดออนจะค้นหาไฟล์ windows_tatip.exe โดยตรวจสอบจากพาธติดตั้งมาตรฐานใน Local AppData ก่อน แล้วจึงตามด้วย Program Files และ Program Files (x86) เป็นทางเลือกสำรอง
3. หากไม่พบไฟล์โปรแกรมเลย คุณจะได้ยินข้อความแจ้งข้อผิดพลาดพร้อมเสียงบี๊บเตือน และการทำงานจะหยุดลง
4. แอ็ดออนจะพยายามบังคับปิดโปรเซส PPA Tatip ที่มีอยู่ เริ่มด้วย taskkill หากยังไม่ได้รับการยืนยันว่าโปรเซสปิดไปแล้ว จะใช้ Stop-Process ของ PowerShell และใช้ wmic เป็นทางเลือกสุดท้าย
5. เริ่มเปิด PPA Tatip ใหม่อีกครั้ง จากนั้นแอ็ดออนจะคอยสุ่มตรวจเช็คเพื่อยืนยันว่าโปรเซสปรากฏขึ้นในรายการงานที่กำลังทำงานอยู่จริงๆ โดยรอสูงสุดประมาณ 2.5 วินาทีต่อการพยายามหนึ่งครั้ง
6. หากการเปิดใหม่ยังไม่ได้รับการยืนยันภายในเวลานั้น แอ็ดออนจะพยายามใหม่อัตโนมัติ (สูงสุด 3 ครั้งโดยค่าเริ่มต้น หรือลองเพียงครั้งเดียวหากปิดการพยายามใหม่อัตโนมัติในตั้งค่า)
7. หาก PPA Tatip ยังคงไม่ทำงานหลังจากพยายามครบทุกครั้งแล้ว คุณจะได้ยินข้อความขอให้ลองกด Windows+P ใหม่อีกครั้ง พร้อมเสียงบี๊บเตือน


หากคุณเพิ่งปลุก PPA Tatip สำเร็จไปภายใน 3 วินาทีที่ผ่านมา การกด Windows+P ซ้ำจะถือว่าไม่มีความจำเป็น: NVDA จะแจ้งคุณว่า PPA Tatip ตื่นพร้อมทำงานอยู่แล้วและเล่นเสียงบี๊บสั้นๆ แทนที่จะไปปิดโปรเซสที่เพิ่งเริ่มทำงานเสร็จ


กระบวนการทั้งหมดนี้ทำงานอยู่เบื้องหลัง (Background Thread) ดังนั้นตัว NVDA จะไม่เกิดอาการค้างในขณะที่กำลังรีสตาร์ท PPA Tatip และหากมีการกดซ้ำขณะที่ระบบกำลังปลุกอยู่ จะได้รับการตอบรับด้วยข้อความ "โปรดรอ" (please wait) แทนที่จะเป็นการเริ่มทำงานซ้ำซ้อน

เปิดตัวเลือก PPA Tatip (กด 2 ครั้ง)

การกด Windows+P 2 ครั้งจะค้นหาไฟล์ openoption.exe ภายในโฟลเดอร์อินเทอร์เฟซของ PPA Tatip ใต้โปรไฟล์ผู้ใช้ของคุณและเปิดขึ้นมา พร้อมประกาศคำว่า "Option" หากไม่พบไฟล์ คุณจะได้ยินข้อความแจ้งข้อผิดพลาดพร้อมเสียงบี๊บเตือน

เมนูจัดการ PPA Tatip (กด 3 ครั้ง)

การกด Windows+P 3 ครั้งจะเปิดหน้าต่างรายการตัวเลือกแบบลอยขนาดเล็กพร้อม 4 ตัวเลือก: ตั้งค่าตัวอ่าน Tatip (Tatip reader setting), สำรองพจนานุกรม Tatip (Backup Tatip dictionary), คืนค่าพจนานุกรม Tatip (Restore Tatip dictionary) และ เปิดโฟลเดอร์ Tatip (Open Tatip folder)


หน้าต่างเมนูสามารถใช้งานด้วยคีย์บอร์ดได้ทั้งหมด: กด Enter เพื่อเลือกรายการที่ไฮไลท์ หรือกด Escape เพื่อปิดเมนูโดยไม่เลือก นอกจากนี้ยังปิดตัวเองให้อัตโนมัติหากปล่อยทิ้งไว้ 15 วินาที และเวลานี้จะเริ่มนับใหม่ทุกครั้งที่คุณกดปุ่มใดๆ ในหน้าต่างเมนู

หน้าต่างตั้งค่าตัวอ่าน Tatip

เมื่อเปิดจากเมนูจัดการ หน้าต่างนี้จะมีช่องตัวเลือก (Checkbox) 3 รายการเพื่อควบคุมพฤติกรรมการปกป้องของแอ็ดออน:


- ข้ามการอ่านตัวอักษรภาษาจีน ญี่ปุ่น และเกาหลี
- ป้องกันโปรแกรมค้างเมื่อโฟกัสที่ปุ่ม Open/OK/Save ในหน้าต่างโต้ตอบ
- พยายามปลุกใหม่อัตโนมัติหาก PPA Tatip ไม่ยอมทำงาน


ทั้ง 3 ตัวเลือกจะเปิดใช้งานไว้เป็นค่าเริ่มต้น การตั้งค่าจะถูกบันทึกทันทีที่คุณกด OK และจะถูกโหลดกลับมาใช้งานใหม่อัตโนมัติเมื่อ NVDA เริ่มทำงานในครั้งต่อไป

ระบบกรองเสียงอ่านตัวอักษรที่เป็นปัญหาอัตโนมัติ

PPAWakeUp จะติดตั้งตัวเองอยู่ด้านหน้าของระบบส่งออกเสียงอ่านของ NVDA เมื่อเปิดใช้งานตั้งค่า "ข้ามการอ่านตัวอักษรภาษาจีน ญี่ปุ่น และเกาหลี" ทุกข้อความที่ NVDA กำลังจะอ่านออกเสียงจะถูกตรวจสอบทีละตัวอักษรเทียบกับตารางช่วงรหัส Unicode ขนาดใหญ่ที่ทราบกันดีว่าเป็นสาเหตุทำให้ PPA Tatip หยุดทำงาน ครอบคลุมถึงอักษรจีน (CJK), ฮิรางานะ, คาตากานะ, ฮันกึล, โบโปโมโฟ และอักษรอื่นๆ ที่เกี่ยวข้อง


ตัวอักษรที่ตรงเงื่อนไขจะถูกลบออกไปอย่างเงียบๆ ก่อนที่ข้อความจะส่งไปถึง PPA Tatip หากการกรองทำให้ข้อความถูกลบจนหมดไม่เหลืออะไรเลย แอ็ดออนจะยกเลิกการอ่านข้อความนั้นไปเลย แทนที่จะส่งข้อความว่างเปล่าไปให้ PPA Tatip และหากกระบวนการกรองเกิดผิดพลาดด้วยเหตุผลใดก็ตาม แอ็ดออนจะย้อนกลับไปอ่านข้อความดั้งเดิมโดยไม่มีการกรอง เพื่อไม่ให้ NVDA เงียบหายไปเนื่องจากฟีเจอร์นี้


เมื่อ NVDA ปิดการทำงานของแอ็ดออน ระบบจะคืนค่าฟังก์ชั่นการอ่านเดิมของ NVDA กลับมา เว้นแต่จะมีแอ็ดออนอื่นซ้อนการทำงานทับไปอีกชั้น ซึ่งในกรณีนั้น PPAWakeUp จะปล่อยทิ้งไว้ตามเดิมเพื่อไม่ให้ไปลบการทำงานของแอ็ดออนอื่นโดยไม่ตั้งใจ

การป้องกันโปรแกรมค้างจากปุ่มในหน้าต่างโต้ตอบ

เมื่อเปิดใช้งานตั้งค่า "ป้องกันโปรแกรมค้างเมื่อโฟกัสที่ปุ่ม Open/OK/Save ในหน้าต่างโต้ตอบ" แอ็ดออนจะคอยเฝ้าดูวัตถุทุกชิ้นที่ได้รับโฟกัส หากปุ่มที่มีชื่อว่า Open, OK, Save หรือ Yes (ทั้งภาษาอังกฤษและภาษาไทย) ได้รับโฟกัส ตัวจับเวลาตรวจสอบ 1.5 วินาทีจะเริ่มทำงาน


เมื่อครบเวลา แอ็ดออนจะตรวจสอบว่าโปรเซส PPA Tatip ยังคงทำงานอยู่หรือไม่ หากพบว่าหายไป แอ็ดออนจะสรุปว่าโปรแกรมค้างอันเนื่องมาจากการโฟกัสปุ่มดังกล่าว และจะเริ่มกระบวนการปลุกใหม่อัตโนมัติเช่นเดียวกับการกด Windows+P 1 ครั้ง โดยที่คุณไม่ต้องกดอะไรเองเลย

สำรองพจนานุกรม Tatip

คัดลอกไฟล์ userdict.txt ของ PPA Tatip จากโฟลเดอร์อินเทอร์เฟซ ไปยังตำแหน่งสำรองเฉพาะภายในโฟลเดอร์การตั้งค่า NVDA ของคุณ คุณจะได้ยินข้อความยืนยันพร้อมบอกพาธปลายทางและเสียงบี๊บแสดงความสำเร็จ หรือข้อความแจ้งข้อผิดพลาดพร้อมเสียงบี๊บเตือนหากไม่พบไฟล์ต้นทางหรือคัดลอกไม่สำเร็จ

คืนค่าพจนานุกรม Tatip

คัดลอกไฟล์ userdict.txt ที่เคยสำรองไว้กลับไปยังโฟลเดอร์อินเทอร์เฟซของ PPA Tatip จากนั้นจะเริ่มกระบวนการปลุกใหม่อัตโนมัติเช่นเดียวกับการกด Windows+P 1 ครั้ง เพื่อให้ PPA Tatip โหลดไฟล์พจนานุกรมที่คืนค่ามาใช้งานทันที หากยังไม่มีไฟล์สำรองอยู่ ระบบจะแจ้งให้คุณทำการสำรองข้อมูลก่อน

เปิดโฟลเดอร์ Tatip

เปิดโฟลเดอร์อินเทอร์เฟซของ PPA Tatip ใน File Explorer โดยตรง พร้อมประกาศคำว่า "เปิดโฟลเดอร์ Tatip แล้ว" เมื่อสำเร็จ หรือแจ้งข้อความผิดพลาดหากไม่พบโฟลเดอร์

การจัดเก็บค่าตั้งค่า

ค่าตัวเลือกทั้งสามรายการจะถูกจัดเก็บในรูปแบบ JSON ไว้ในไฟล์ settings.json ภายในโฟลเดอร์ย่อย ChaiChaimee\PPAWakeUp ของโฟลเดอร์การตั้งค่า NVDA ของคุณ หากไฟล์สูญหายหรือไม่สามารถอ่านได้ แอ็ดออนจะย้อนกลับไปใช้ค่าเริ่มต้น (เปิดการปกป้องทั้งสามรายการ) โดยไม่ขัดจังหวะการเริ่มทำงานของโปรแกรม
